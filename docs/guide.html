Wordle Help Guide

The game selects a hidden five-letter word. You have six guesses to find it. Enter one letter in each box to form a valid five-letter word. After each guess, use the feedback to help choose your next word.

Colour Mode

  • Green: The letter is in the correct position.
  • Amber: The letter is in the answer, but in a different position.
  • Dark grey: This occurrence of the letter does not match a remaining letter in the answer.

Letters can appear more than once. If your guess contains more copies of a letter than the answer, the extra copies are marked absent.

Colour vs Access Differences

Both modes use the same five-letter guessing rules. Colour mode displays coloured letter feedback. Access mode uses symbols and a written feedback panel so the clues can be understood without relying on colour.

  • Tick: The letter is in the correct position.
  • Question mark: The letter is in the answer, but in a different position.
  • Cross: This occurrence of the letter is marked absent.

The Access mode feedback panel describes the latest guess and lists the letter positions confirmed so far.

Auto Answer (Speed Play/Tab Answer)

Typing a letter automatically moves focus to the next box. Once all five boxes are filled, leaving the final box submits your guess. This can happen automatically after typing the fifth letter, or when you press Tab or click away from the final box.

Invalid Guesses

Your guess must contain five letters and appear in the game's word list. An invalid word produces an error message without using an attempt. Close the message and enter another word.

Winning, Losing and Restarting

Find the hidden word within six guesses to win. If all six guesses are incorrect, the game ends and reveals the answer. Select Reset Game to clear the board and start a new round.
